# Карточка проекта К16 · математика

## Исследовательский вопрос
В каких случаях LLM-as-a-Judge на задачах counting_and_probability ошибается при определении корректности математического решения относительно эталонной метки correct/incorrect?

## Данные и срез
EleutherAI/hendrycks_math (MATH, Hendrycks et al.); конфигурация counting_and_probability; для пилота — 30 задач из train, для основного эксперимента — 100–200 задач; лицензия: MIT License

## Эталон и метод
Эталонный исход или прокси: Эталоном считаем заранее известную метку correct/incorrect. Исходное эталонное решение MATH считаем корректным, а решение с контролируемо внесённой математической ошибкой — некорректным. Такой подход не покрывает все возможные альтернативные корректные решения и зависит от качества создаваемых ошибочных примеров.

Оцениваемый оценщик: LLM-as-a-Judge: одна зафиксированная языковая модель получает условие задачи и проверяемое решение и возвращает verdict correct или incorrect.

Базовое сравнение: Проверка только финального ответа: финальный ответ проверяемого решения сравнивается с финальным ответом эталонного решения.

## Метрика и критерий
Метрика ошибки: Error Rate = количество случаев, когда verdict оценщика не совпал с эталонной меткой correct/incorrect, делённое на общее количество проверенных решений. Метрика считается отдельно для LLM-as-a-Judge и baseline.

Численный критерий успеха: Предварительный критерий: Error Rate LLM-as-a-Judge не более 15% и ниже Error Rate baseline. Окончательный порог при необходимости обсудить с куратором.

## Риск и границы
Возможная ошибка оценщика: Оценщик может получить искусственно высокий результат, если внесённые ошибки слишком простые или шаблонные. Тогда LLM может распознавать характер ошибки, а не полноценно проверять математическое рассуждение.

За границами проекта: Не обучаем и не дообучаем собственную модель; не исследуем весь MATH; не рассматриваем все математические категории; не сравниваем большое количество LLM; не создаём универсальную систему проверки математических доказательств.
